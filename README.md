## ✨ Features

- **Responsive Design**: Mobile-first approach, works on all devices
- **Modern Navigation**: Enhanced header with gradient effects and smooth animations
- **Service Showcase**: Dedicated sections for Mehndi, Nail Art, and Makeup
- **Interactive Gallery**: Filterable portfolio with 18 images (6 each category)
- **Testimonials Slider**: Customer reviews with smooth transitions
- **Booking Form**: Easy appointment booking with contact information
- **Elegant Theme**: Pink tulip and baby's breath floral accents

## 🎨 Design Elements

- **Color Scheme**: Baby Pink, White, Deep Pink accents
- **Typography**: Playfair Display (headings) + Montserrat (body)
- **Icons**: Font Awesome 6.4.0
- **Animations**: AOS (Animate On Scroll) library

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process required - it's ready to use!

## 📝 Customization

To customize for your own parlour:

1. Update contact details in `index.html` (top bar and contact section)
2. Replace images in the `images/` folder
3. Modify services and pricing in the services section
4. Update color scheme in CSS variables (`:root` section in `style.css`)
5. Add/remove testimonials as needed
